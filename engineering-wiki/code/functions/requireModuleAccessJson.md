# requireModuleAccessJson()

Hard gate for a module's JSON write APIs: refuse a denied analyst with a 403. Authoritative (DB-checked). The API twin of `requireModuleAccess()`. Call right after connecting, e.g. requireModuleAccessJson('assets', `$conn`); Shared READ endpoints that other modules or the login page depend on must NOT call this — guarding those would break normal cross-module flows.

```php
function requireModuleAccessJson(string $moduleKey, ?PDO $conn = null): void
```

Defined in [includes/functions.php](/code/files/includes/functions.php.md), line 367.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `$moduleKey` | `string` |  | the module the endpoint belongs to, e.g. 'assets'; 'system' means administrators only |
| `$conn` | `?PDO` | `null` | The database connection. *([standard](/handbook/standard-parameters.md))* |

**Returns:** `void`

[analystCanAccessModule()](/code/functions/analystCanAccessModule.md), [connectToDatabase()](/code/functions/connectToDatabase.md)
