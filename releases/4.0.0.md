## What this release is about

**FreeITSM 4.0 needs PHP 8.1 or newer.** That is why the version number moved to 4: it is the one thing this upgrade asks of you. If you run the Docker image you already have PHP 8.4 and need do nothing; otherwise check your PHP version before upgrading (see Upgrading below). Alongside it, System → Analysts can now be searched, filtered, grouped and paged, the official Docker image finally includes LDAP, and Domains can be told never to send your DNS questions outside your own network.

## New features

- **Find people in the Analysts list.** System → Analysts gains a search box, filters (company, team, status, administrator, sign-in method, never signed in) and paging. Group the list by company, team, department, job title, status, administrator or sign-in method - and then by a second level - shown as a collapsible tree, as tabs, or on one page with a list to jump between groups. Someone in two teams appears under both. Each person's layout is remembered, and an administrator can make a view the default for everyone. It starts as the plain list you had, so nothing changes until you choose something. Thanks to @duongtuanan for the request ([#208](https://github.com/edmozley/freeitsm/issues/208)). Details: [Finding people in the Analysts list](https://github.com/edmozley/freeitsm/wiki/Analyst-List).
- **Domains: "This server only - never public DNS".** A new choice under Domains → Settings → Monitoring → DNS resolver. Until now, when the server's own resolver could not answer, the question was asked of Google instead, and a few kinds of question always went to Google - so internal names could leave your network. With this choice nothing is asked of a public DNS service, ever; the one check that needs one (DNSSEC) shows as not checked and costs the domain nothing. Thanks to @Dr4inder, who spotted it ([#203](https://github.com/edmozley/freeitsm/issues/203)). A fuller internal-monitoring mode for Domains is designed and open for comment: [Internal monitoring in Domains](https://github.com/edmozley/freeitsm/wiki/Domains-Internal-Monitoring-Design).
- **Hide the waffle button.** If you use the sidebar, Preferences → Display → Sidebar → Waffle button can now hide the waffle button at the top of the screen. Thanks to Kraleemil ([discussion #124](https://github.com/edmozley/freeitsm/discussions/124)).

## Improvements

- **The Docker image includes LDAP, zip and international domain support.** LDAP and Active Directory sign-in now work in the official image without building your own, and so do uploading LMS courses, reading Word files in the RFP Builder and international domain names in Domains. If you built a derived image to add LDAP, you can go back to the official one. Thanks to @Dr4inder ([#207](https://github.com/edmozley/freeitsm/issues/207)). Details: [The Docker image was missing PHP extensions](https://github.com/edmozley/freeitsm/wiki/Docker-Image-Missing-PHP-Extensions).
- **A clear message on an old PHP.** Opening FreeITSM on a PHP older than 8.1 now says so in a sentence, with a link to [how to upgrade PHP](https://github.com/edmozley/freeitsm/wiki/Upgrading-PHP), instead of an error or a blank page. The setup page reports LDAP, zip and international domain support among its checks.
- **The sidebar scrolls.** When its modules do not all fit, arrows appear at the top and bottom of the sidebar, and the module you are in is kept in view.
- **Recent opens beside the sidebar**, by its Recent button, instead of up under the waffle button.
- **The waffle panel stands out in dark mode**, rather than blending into the page behind it.
- **Messaging channels each have their own badge.** On Tickets → Settings → Messaging, Slack and web chat channels are now labelled as such.

## Fixes

- **Recent was hidden behind the sidebar** when module names were set to open on hover.
- **Uploading an LMS course or a Word file to the RFP Builder could fail with no explanation** on a server without PHP's zip extension. It now says what is missing.
- **Slack and web chat channels were labelled "Twilio"** on the Messaging settings tab.
- **The Basic IMAP mailbox option read "username &amp;amp; password"** instead of "username & password".

## Upgrading

**First, check your PHP version.** FreeITSM 4.0 needs **PHP 8.1 or newer**; 8.3 or 8.4 is recommended.

- **Docker:** nothing to do - the image runs PHP 8.4.
- **Anything else:** open `/setup/` before upgrading - its **PHP version** row shows yours (sign in as an administrator to see the exact version). If it is older than 8.1, upgrade PHP first - [Upgrading PHP](https://github.com/edmozley/freeitsm/wiki/Upgrading-PHP) covers Ubuntu, Debian, RHEL, cPanel and WAMP. Nothing in FreeITSM or its database needs changing for the new PHP. If you upgrade FreeITSM first by mistake, every page will tell you what is wrong rather than failing.

Then, as usual:

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5). This release updates cached scripts.

Things to know:

- The new Analysts list controls and some new Domains text are in English for now in eight languages; translations follow.
- Basic IMAP mailboxes still do not work in the Docker image - PHP no longer ships the extension they need, and current Debian no longer packages its library. Microsoft 365 and Gmail mailboxes are not affected. Details: [Basic IMAP mailboxes](https://github.com/edmozley/freeitsm/wiki/Basic-IMAP-Mailboxes).

## Rollback

Safe. This release changes nothing in the database, so you can go back to 3.16.0.
