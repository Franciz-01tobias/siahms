## What this release is about

A small release for Files. When an upload failed because the server sent back something unexpected, the Transfers window only said "HTTP 200", which told you nothing. It now shows the start of what the server actually said, such as a PHP warning about a folder it could not write to, so you can see the cause and fix it. Nothing else changes.

## Improvements

- **Failed uploads explain themselves.** In Files, an upload or action that fails with an unexpected reply from the server now shows that reply in the Transfers window, or says the reply was empty, instead of a bare "HTTP 200". The usual cause is a storage folder the web server cannot write to, and the message will usually point straight at it.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5) - this release updates cached JavaScript.

## Rollback

Safe - nothing was changed in the database, so you can go back to 3.5.1 with the code alone.
