## What this release is about

**Upgrade this one promptly** - it fixes a security issue present in every release from 1.0.0 to 3.13.0, in the worst case reachable by anyone who can send your service desk an email. Alongside it, two things people asked for: a **case report** that turns a ticket and all the work behind it into one printable document for a reviewer or an auditor, and **asset pages that fit the kind of asset** - a monitor no longer shows empty CPU, memory and Devices boxes. Run Database Verification after upgrading.

## Security

- **Text could break out of an attribute and run a script.** Present in every release from 1.0.0 to 3.13.0. FreeITSM escapes text people have typed before putting it into a page, but the escaping missed the double quote, so text containing one could end the attribute it was placed in and add its own event handler, which then ran in the browser of whoever was looking, with their access. The worst case needed no account: a ticket raised by email keeps the sender's subject, and when that ticket is linked to another (parent, child, duplicate, related), the subject becomes the tooltip of its badge - pointing at the badge ran the handler. Other cases needed someone who can already edit the text, such as a Process Mapper connector label, where it was found. Every escaping helper in FreeITSM now escapes quotes. Upgrading is the fix; nothing else needs doing. Details: [Escaped text could leave its attribute](https://github.com/edmozley/freeitsm/wiki/Escaped-Text-Could-Leave-Its-Attribute).

## New features

- **Case reports.** **Export** in a ticket's toolbar opens the ticket and every task linked to it as one printable record: the overview, every message, the notes, checklists, each task with its checklist results, exception notes, form answers, procedures followed and comments, the history, and an index of the documents with their fingerprints. Tick the sections you want, choose a cover page, a contents page, page breaks and page numbers, then **Print → Save as PDF**. Internal notes stay out unless you tick them in, anything the person printing may not see is counted but never named, and printing is recorded on the ticket. A task with no ticket has the same report from the document button in its window. See [Case reports](https://github.com/edmozley/freeitsm/wiki/Case-Report). Requested in [#204](https://github.com/edmozley/freeitsm/issues/204).
- **A page that fits each kind of asset.** **Assets → Settings → Asset types → Layout** chooses which built-in details (Make and model, Hardware, Operating system, Reporting, Storage) and which tabs a type shows, and the order of its tabs - with Peripheral, Network equipment and Mobile device starting points. Only the page changes: nothing stored is touched, inventory keeps arriving, and if an asset holds details its type hides, it says so and **Show them** brings them back. Every type starts with everything shown, so nothing changes until you edit one. See [Asset type layouts](https://github.com/edmozley/freeitsm/wiki/Asset-Type-Layouts). Requested in [#200](https://github.com/edmozley/freeitsm/issues/200).

## Improvements

- **Process Mapper: the full name of a process is always readable.** The open process's whole name is shown at the top of the page, pointing at a process in the list shows a preview with its full name, description, steps, who created it and when it was last updated, and **/** or **Alt+Shift+O** jumps to the list from anywhere so you can move through it with the arrow keys. Requested in [#202](https://github.com/edmozley/freeitsm/issues/202).
- **Bengali, Indonesian, Marathi, Russian and Tamil are complete** up to 3.12.0 - every screen, including the fourteen modules that had never been translated into them. The screens new in 3.13.0 and this release are in English in every other language for now, and will be translated in a later release.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification** - it adds the table for asset type layouts.
3. Hard-refresh your browser (Ctrl-F5) - this release updates cached scripts on most pages, and the security fix is in them.

## Rollback

Safe - nothing was removed from the database, so you can go back to 3.13.0. Going back reopens the security issue above.
