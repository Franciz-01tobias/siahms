## What this release is about

If you run FreeITSM for more than one company, a workflow can now belong to one of them instead of running for everyone, and a project only lists people who can actually open it. Webhook deliveries get settings for how often and how long to try, and no longer get stuck. Several libraries that ship with FreeITSM (the text editor and the PDF tools) have been updated to versions with published security fixes, which is why this release follows 4.0.0 on the same day.

## Security

- **The bundled text editor and PDF libraries are updated.** TinyMCE (the editor in Tickets, Knowledge and elsewhere) moves to 8.10.0, which fixes a stored cross-site scripting issue in its media plugin. The PDF tools move to jsPDF 4.2.1, which fixes several published vulnerabilities, and the code highlighter Prism moves to 1.30.0. The change PDF no longer uses a separate library that carried its own older copy of jsPDF. Every PDF export and the editors were checked in a browser after the update. All versions up to and including 4.0.0 are affected; upgrading is all you need to do, followed by the hard refresh below so browsers load the new files.

## New features

- **Company-specific workflows.** On a multi-company install, Runs for in the workflow editor makes a workflow one company's own: it runs only for that company's tickets and events, and can only act on that company's records. Every existing workflow stays shared and runs for everyone, as before. Shared workflows can be changed only by someone who can see every company; anyone else sees them read-only. The run log shows each analyst only the companies they can see, and the REST API follows each key's company scope. Single-company installs see no change. Thanks to @duongtuanan for the request ([#209](https://github.com/edmozley/freeitsm/issues/209)). Details: [Workflows - Companies](https://github.com/edmozley/freeitsm/wiki/Workflows#companies).
- **Three new workflow actions:** Assign ticket to team, Set ticket department and Set ticket category. They are recorded in the ticket's history like a change made on screen.
- **Webhook delivery settings.** System → Webhooks → Delivery sets how many times a delivery is tried before giving up, how long to wait for the receiving end, and whether a send cut off part-way is retried or left for you to replay. Every send now carries an ID the receiving end can use to ignore a repeat.

## Improvements

- **A project only offers people who can see its company.** The pickers for analysts, teams and the project manager list only those who can open the project, in the same way a Person from People already had to belong to its company. Anyone added before stays listed with a note. Thanks to @duongtuanan ([#210](https://github.com/edmozley/freeitsm/issues/210)).
- **The Projects help explains what a Person is for**: someone from People has no FreeITSM account; they are on the project for its roles, RACI, stakeholder map and communications plan.

## Fixes

- **A webhook delivery could stay "delivering" for ever**, never retried and never replayable, if the delivery run was cut off part-way.
- **The "Create a task" workflow action always failed.**
- **Test fire skipped every workflow that had a condition.**
- **"Expand the newest message" expanded the oldest one** on a long ticket.
- **Tickets → Settings stopped working for a role given only some of its tabs**: Save buttons on later tabs did nothing. Ticket numbering also now follows its own permission rather than the General tab's.
- **Rota "Include weekends" could never be saved.**

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**. It adds the company column to workflows and their run log.
3. Hard-refresh your browser (Ctrl-F5). This release updates the editor, PDF and other cached scripts.

Things to know:

- The new workflow and webhook settings text is in English for now in eight languages; translations follow.

## Rollback

Safe. This release only adds to the database, so you can go back to 4.0.0.
