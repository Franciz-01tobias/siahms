## What this release is about

Files gets **shortcuts to Knowledge articles**, Windows-style **wildcards** in search, and Cut and Copy that work with shortcuts. A new **System → Engineering wiki** is a reference to how FreeITSM itself is built - every file, function and database table, readable in the browser - for whoever looks after or extends your install. Lease alerts stop nagging about machines that have already gone back. It also fixes a security issue in the AI chat, so upgrade if you use Ask AI. Nothing breaks, and there are no database changes.

## Security

- **An answer in the AI chat could run script in an analyst's browser.** The **Ask AI** chat on a ticket and the AI chat in Knowledge showed the model's answer without making it safe first. The model reads ticket and article text, which customers can write, so a crafted ticket could steer the answer into something that ran in the browser of the analyst reading it. Answers are now made safe before they are shown, and bold, lists, code and article links still work. Present since 1.0.0.

Nothing to do beyond upgrading.

## New features

- **Shortcuts to Knowledge articles in Files.** Right-click a folder or the desktop and choose **Shortcut to article...** to pin an article alongside your files. Double-click it to read the article in a window, with **Open in Knowledge** to go to the full page. People only see a shortcut if they are allowed to read the article.
- **System → Engineering wiki.** A reference to the FreeITSM codebase for administrators: a page for every file, function and database table, saying what it does, what calls it, which tables it reads and writes, and who is allowed to call each API endpoint. It works like a browser - tabs, back and forward, a split view, and a right-click menu on links - and a **Rescan** button brings it up to date if you change the code on your install. It comes with the release, ready to read.

## Improvements

- **Files search and the folder filter accept wildcards** - `*.png`, `report*`, `budget-202?` - the way Windows does. Plain text still finds a match anywhere in the name.
- **When an upload fails in Files**, the failed row in Transfers has a **Get help with this** link that opens Help at a new section explaining each upload error and how to fix it.
- **The module menu shows five modules per row**, so all of them fit on screen instead of running off the bottom.

## Fixes

- **Leased machines that had already gone back** - returned, bought out, or any other closed outcome - still counted on the Watchtower lease card and still got a "Lease ends" calendar entry. They no longer do, and changing a machine's outcome updates the calendar straight away.
- **Cut and Copy were greyed out in Files** whenever a shortcut was among the selected items. Shortcuts now cut, copy and paste like files.
- **The earned value line on a project's Budget tab dipped when tasks were added.** It now only rises, and today's figures (EV, CPI, SPI, EAC) are unchanged.
- **Opening a link to a Knowledge article** flashed the folder's article list for a moment first.
- **The Triage queue and Tickets → Settings → Activity** ignored dark mode.
- **Files said "1 items"** in the status bar.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**. This release changes nothing in the database, but it is a good habit.
3. Hard-refresh your browser (Ctrl-F5) - this release updates cached JavaScript.

## Rollback

Rollback: safe - this release makes no database changes.
