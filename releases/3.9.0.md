## What this release is about

**Fixes System → Teams, broken in 3.7.0, 3.8.0 and 3.8.1** - the list of teams never loaded and Add did nothing, in every language ([#186](https://github.com/edmozley/freeitsm/issues/186)). If you are on any of those versions, upgrade.

Contracts, software licences, domains, leases and projects now all offer **every currency in use in the world**, from one list. Before, Contracts offered 19, Software Licences three, and the rest asked you to type a code. A new **System → Currencies** page puts your favourite currencies at the top of every list, sets the currency new records start in, and decides how amounts are written - `£1,234.56`, `1.234,56 €` or `Rp 1.500.000`. Anyone who writes money differently can choose their own way in Preferences. Each analyst can also **put the modules in their own order**, and administrators can **put the Watchtower cards in order** for everybody. Run Database Verification after upgrading: it adds two columns.

## New features

- **Every currency, everywhere.** The currency list on contracts, software licences, domains, lease schedules and projects now holds every currency in use - the Indonesian rupiah, the Kenyan shilling, the Thai baht and the rest - and they are the same list in every module. Domains, leases and projects no longer ask you to type a code, so a typo can no longer slip in. Requested in [#189](https://github.com/edmozley/freeitsm/issues/189).
- **System → Currencies.** Pick up to **five favourites** to sit at the top of every currency list, and mark one as the **default** that new contracts, licences, domains, leases and projects start in. Choose how amounts are written: the separators (`1,234.56`, `1.234,56`, `1 234,56`, Swiss `1'234.56` or Indian `12,34,567.89`), whether the symbol or the code goes before or after, and the decimal places. Each currency gets its own decimal places by default, so yen have none and the rupiah is written the Indonesian way, without `,00`. You can also give one currency a format of its own - rupiah the Indonesian way while everything else stays British, say. See [Currencies](https://github.com/edmozley/freeitsm/wiki/Currencies) on the wiki.
- **Preferences → Money.** Each analyst can choose their own way of writing amounts, for every currency or just some, without changing anything for anyone else.
- **Your own module order.** Under **Preferences → Display → Module order**, put the modules you use most first - by dragging, with the arrow buttons, or with Alt and the arrow keys. The waffle menu, the home page and the Ctrl+K "Go to" list all follow it, so Ctrl+K then Enter opens your first module. It is yours alone, it never changes which modules you can open, and **Reset** puts the standard order back. Requested in [#187](https://github.com/edmozley/freeitsm/issues/187).
- **Hide done, on the Tasks board and list.** A tick in the Tasks sidebar leaves out everything that is finished - on the board the Done columns go too. It is remembered for you. Requested in [#184](https://github.com/edmozley/freeitsm/issues/184).
- **Choose which subtasks the cards list.** **Subtasks on cards** in the Tasks sidebar: All, Open (only the ones still to do) or None. Click a card's count, such as 1/4, to show or hide that one card's subtasks. It replaces the Preferences switch "hide them once all are complete", which becomes Open. Also [#184](https://github.com/edmozley/freeitsm/issues/184).
- **Tasks in order within a project stage.** On a project's Plan tab, drag a task up or down within its stage - or press up or down on its handle, or use Up and Down on a phone. Also [#184](https://github.com/edmozley/freeitsm/issues/184).
- **Watchtower card order.** **Watchtower → Settings → Cards** now puts the cards in order as well as showing or hiding them, for everybody, by whoever can already choose which cards appear. Each person still sees only the cards they have access to, in that order; **Reset order** puts the standard order back. Also requested in [#187](https://github.com/edmozley/freeitsm/issues/187).

## Improvements

- **The large task window's Details tab uses its width.** In the tabs layout, fields now sit up to six to a row on a wide screen instead of two, so the description is on screen without scrolling.
- **A domain's cost centre comes from System → Cost centres**, like a contract's, instead of being typed in. Upgrading links any typed-in value to the cost centre with that code; anything that matches none stays visible until somebody picks one. Requested in [#188](https://github.com/edmozley/freeitsm/issues/188).
- **Amounts look the same everywhere.** A contract value, a licence cost, a domain's renewal fee, a lease and a project budget are now written the same way, in each person's own format, on screen and in report packs.
- **Changing a project's currency** is a pick from the list instead of typing a code into a box.
- **Projects → Settings → Budget → Currency for new projects** is a list, and when it is left unset it follows the default in System → Currencies.
- **The REST API and imports refuse a code that is not a real currency**, with the same message in every module, instead of storing whatever three letters arrived.
- **A module or Watchtower card added in a future update appears on its own**, in its usual place, even for people who have put theirs in their own order.

## Fixes

- **A domain's transfer lock was shown as off when the registry had not said either way.** Many country registries answer only "active"; those domains now show the lock as *not known* rather than as a warning. Reported in [#188](https://github.com/edmozley/freeitsm/issues/188).
- **Subtasks had no names in the task side panel** - just a tick box, a priority and two dates - and the subtask Add row pushed the panel sideways. Each subtask now has its name on its own line when the panel is narrow. Reported in [#184](https://github.com/edmozley/freeitsm/issues/184).
- **A finished task still said Overdue** on its card and in the task list. Also [#184](https://github.com/edmozley/freeitsm/issues/184).
- **Ticking a subtask on the board opened it** instead of marking it done. The tick now completes it; the rest of the row still opens it.
- **The green progress bar on a card never filled in** as its subtasks were completed.
- **System → Teams never showed its list of teams, and Add did nothing**, since 3.7.0 and in every language, so no team could be created or changed. Reported in [#186](https://github.com/edmozley/freeitsm/issues/186).
- **The Projects card was grey on Watchtower → Settings** instead of its module colour.
- **Watchtower settings said "Saved" for a change you had no permission to make**, and quietly threw the change away. It now says you do not have permission.
- **Watchtower's help gave the wrong numbers** - ten cards, and six that cannot narrow to *Mine*. There are thirteen, and eight cannot narrow.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**. This release adds two columns: one for the order of tasks within a project stage, and one linking each domain to a cost centre (any cost centre typed into a domain is linked to the one with that code). Until you do, everything else works and the Plan keeps its current order.
3. Hard-refresh your browser (Ctrl-F5) - this release updates cached JavaScript and stylesheets.

**Two things to know:**

- **Amounts may look slightly different.** Everything now follows one format, which out of the box is `£1,234.56`. Some screens used to follow the browser's own regional settings, and a contract value used to read `GBP 45,000.00`. If your organisation writes money differently, set it once in **System → Currencies**.
- **A currency someone typed by mistake must be fixed before that record saves again.** If a domain, lease or project holds a code that is not a real currency (`UKP`, say), **System → Currencies** lists it at the bottom of the page with how many records have it. The record still shows the code until somebody picks a real currency. Old records in a currency that has since been retired, such as the Bulgarian lev, are unaffected.

## Rollback

Safe - this release only adds two columns to the database, so you can go back to 3.8.1 with the code alone.
