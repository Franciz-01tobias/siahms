## What this release is about

Documents attached to a Knowledge article can now be **downloaded by customers from the self-service Help Centre**, with a switch to hold any one back. When an analyst leaves, **System → Analysts** now helps you hand their work on and then deactivate, anonymise or delete them - instead of a database error. Ticket folder numbers are fixed for anyone in a team that has no departments, and the Help Centre gets a round of polish. Run Database Verification after upgrading: it adds one column.

## New features

- **Documents in the Help Centre.** Attach a file to a Knowledge article and customers who can read that article in the self-service Help Centre can download it, shown as tiles with an icon for each file type. Each document has a **Show** / **Hide** button in the article editor, so a customer guide and an internal checklist can sit on the same article and only the guide is offered. The article list shows a paperclip and "3 documents" on articles that have them, and changing an article's audience to customers warns you before its documents go with it. There is a new help page, **Knowledge → Help → Documents and the Help Centre**. Requested in [#177](https://github.com/edmozley/freeitsm/issues/177).
- **When someone leaves.** The bin icon on an analyst in **System → Analysts** now opens a window that lists their open work - tickets, problems, changes, tasks, and the articles, projects, contracts and domains they own - and moves it to another analyst, or leaves it unassigned, the same way as reassigning each item by hand. It lists anything else set up for them, such as a form that sends approvals to them, for you to change. Then you choose:
  - **Deactivate** - they can no longer sign in, and their name stays on everything they did. The right choice for almost every leaver, and it can be undone.
  - **Anonymise** - their name and contact details are removed and their records stay, credited to "Former analyst #42". This gives you a way to act on a request to be forgotten, as part of meeting obligations such as GDPR, while keeping your service history intact. It changes the names FreeITSM stores against the account, not names someone typed into the text of a note or an email.
  - **Delete** - only for an account with no history, such as one created by mistake.

## Improvements

- **System → Teams warns about a team with members but no departments**, and when you have no departments yet, the team's departments window points you to **Tickets → Settings → Departments**.
- **The Help Centre reads better.** Articles have proper spacing between paragraphs and indented lists, previews end with "…" instead of stopping mid-word, cards line up across each row, the layout buttons disappear while you read an article, and **Back to all articles** is a proper button.

## Fixes

- **Ticket folders showed 0 for anyone in a team with no departments** - All Tickets, every status and every other analyst's folder - while their own folder still had a number. Those folders now count the tickets that have no department, as they always should have. A department you have deliberately not linked to a team is still left out of that team's folders. Debug Tool **D018** follows the corrected rule.
- **Deleting an analyst showed a raw database error** once they had a dashboard widget saved. See *When someone leaves* above. Reported in [#178](https://github.com/edmozley/freeitsm/issues/178).
- **On an install with more than one company, the Analyst folders listed every analyst**, so analysts at one client could see the names of another client's analysts. They now show only analysts who can work in the company you are viewing. Reported in [#176](https://github.com/edmozley/freeitsm/issues/176).
- **Help Centre previews showed codes such as `&gt;` and `&amp;`** instead of ">" and "&", on the Help Centre, the portal dashboard and New Ticket's suggestions.
- **A lease could not be scrolled on a phone.**

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**. This release adds one column, for the Help Centre's Show / Hide setting.
3. Hard-refresh your browser (Ctrl-F5) - this release updates cached JavaScript and stylesheets.

**One thing to know:** documents that were already attached to articles before this release start **hidden**, so nothing reaches customers just because you upgraded. To offer one, open the article, click **Edit**, and click **Show** on the document. Documents you attach from now on start shown.

## Rollback

Safe - this release only adds a column to the database, so you can go back to 3.6.1 with the code alone.
