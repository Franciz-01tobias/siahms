## What this release is about

If your team uses FreeITSM in **Danish, German, Spanish, French, Gujarati, Hindi, Malayalam, Malay, Norwegian (bokmål and nynorsk), Polish, Brazilian Portuguese or Ukrainian**, every screen is now in your language again. Since 2.5.0 each release added English text faster than the translations kept up, so those languages had slipped to about 70% - whole modules such as **Projects, Domains, Files and People** appeared entirely in English. This release brings all thirteen back to 100%. Nothing else changes: no new features, nothing in the database.

## Improvements

- **Projects, Domains, Files and People in thirteen languages.** These four modules had never been translated into any language; now they are, help pages included, in all thirteen listed above.
- **Everything added between 2.5.0 and 3.10.0 is translated** in the same thirteen languages - report packs, currencies and cost centres, change approvals and evidence, asset leases and labels, LMS competency tests, custom ticket fields, the reading pane, the sidebar, repeating tasks and subtasks, and the rest.
- **The three kinds of project timebox read as three different words.** Projects run in phases, stages or sprints, and each language now uses one word for each, everywhere in the module.

## Fixes

- **Some screens showed a translation that no longer matched the English.** Where the English wording had changed since 2.5.0 (about 860 strings across the languages), the old translation stayed in place and could describe how a screen used to work. Those out-of-date translations were removed: the thirteen languages above have the new wording translated, and the others now show the current English rather than an outdated sentence.

## Still to come

**Afrikaans, Bengali, Indonesian, Italian, Kannada, Marathi, Dutch, Punjabi, Russian, Tamil and Telugu** are still partly translated. Anything not yet in those languages shows in English, as before.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**. This release changes nothing in the database, so it will find nothing to do.
3. Hard-refresh your browser (Ctrl-F5).

## Rollback

Safe - this release does not touch the database, so you can go back to 3.10.0.
