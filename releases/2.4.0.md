## What this release is about

Language. Twelve of the twenty-four languages FreeITSM offers are now complete, where five were before. Brazilian Portuguese, French, Gujarati, Malay, Norwegian in both written standards and Ukrainian have all been finished, and Danish, German, Hindi, Polish and Spanish have been brought back to complete after newer features left them behind.

Malayalam is at 95% and will follow shortly. The remaining eleven languages sit at about a third translated, and they are next.

If you run FreeITSM in one of the finished languages, the difference is not a polished phrase here and there. French was two thirds English before this release, and System, Contracts, Self-service and Network Mapper had no French at all. Whole screens that used to fall back to English are now in your language, including the Checklists and War Room modules, which until now existed in no language but English.

Nothing about this upgrade asks anything of you. There are no new settings, no database changes and no new features to learn.

## Improvements

- **Whole modules exist in your language for the first time.** Checklists and SOPs had never been translated into anything at all. War Room, the system wiki and the setup screens were missing from most languages, and Contracts, System, Self-service and Network Mapper were missing from a dozen.

- **Three Brazilian Portuguese strings showed a broken variable.** The workflow help text uses `{{variables}}` as an example of the syntax you type into a template, and the example itself had been translated, so copying it produced something the workflow engine could not understand. Every language now shows that example exactly as it has to be typed.

- **The languages that were finished no longer quietly fall behind.** Every language that reached 100% had since drifted, because each new feature adds English text and nothing reported it as missing. FreeITSM now checks this whenever the code changes, so a language that is complete stays complete.

## A note on what is still in English

Some screens are still shown in English in every language, including the main Checklists screens and the password reset pages. This is not a gap in the translations. Those screens were never connected to the translation system in the first place, so there was nothing for a translator to translate. Connecting them is the next piece of language work, and it is why this release says twelve languages are complete rather than claiming the whole product is.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5).

Your language is chosen per person under **Preferences**, and anything not yet translated falls back to English, so nothing breaks if a screen is missing a phrase.
